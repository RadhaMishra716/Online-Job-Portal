# Online Job Portal

## Project Overview

The Online Job Portal is a web-based application developed using Java, JSP, Servlets, JDBC, MySQL, and Apache Tomcat. It provides a platform where recruiters can post job vacancies and job seekers can search and apply for available jobs. The project is designed to simplify the recruitment process with a user-friendly interface and secure database management.

---

##  Features

- User Registration & Login
- Recruiter Registration & Login
- Post New Job Vacancies
- Search Available Jobs
- Manage Job Listings
- MySQL Database Integration
- Responsive User Interface
- Secure Session Management

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/RadhaMishra716/Online-Job-Portal.git
```

### 2. Configure Database

- Create a MySQL database.
- Import the SQL file provided with the project.
- Update the database username and password in the JDBC configuration.

### 3. Run the Project

- Import the project into Eclipse or IntelliJ IDEA.
- Configure Apache Tomcat Server.
- Run the project.

## Usage

- Register as a User or Recruiter.
